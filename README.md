# Política de Privacidade — CESAP Conecta

Página pública e estática da Política de Privacidade da CESAP Conecta, solução operada pelo Centro de Saúde Aplicada - CESAP (CNPJ 01.565.345/0001-55).

- **Endereço público:** https://privacidade.grupocesap.com
- **Hospedagem:** GitHub Pages, publicado a partir da branch `main` (raiz do repositório)

## Conteúdo

| Arquivo | Função |
| --- | --- |
| `index.html` | Texto integral da Política, em HTML estático |
| `CNAME` | Domínio personalizado usado pelo GitHub Pages |
| `.nojekyll` | Publica os arquivos como estão, sem processamento do Jekyll |

A página não usa scripts, cookies, fontes externas, Pixel da Meta nem ferramentas de análise ou rastreamento. Uma política de segurança de conteúdo (CSP) declarada no `index.html` bloqueia a execução de scripts.

Este repositório contém apenas arquivos públicos. Não adicione segredos, credenciais, variáveis de ambiente nem código de outros sistemas.

## Como atualizar a Política

1. Edite o texto em `index.html`.
2. Atualize a data de **Última atualização** no topo e na Seção 15.
3. Faça commit na branch `main`. O GitHub Pages publica a nova versão em poucos minutos.

Dúvidas sobre privacidade e proteção de dados: privacidade@grupocesap.com
